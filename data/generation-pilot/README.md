# 브리핑 생성 비교 · 2026-09-23

비교 대상은 MTS(실험·평가 기술)와 Zavegepant PBPK(ADME·PK/PD) 2편이다. 앱의 **논문 선택**에서 대상을 바꾼 뒤 **기존 브리핑 / 시범 생성본**을 전환한다. 아래 첫 시험 기록과 두 번째 분야 시험 기록은 각각의 생성·검토 범위를 나타낸다.

## 첫 시험 · MTS

이번 시험은 **현재 Codex 세션에서 원자료로 새 초안을 만든 뒤 앱에서 기존본과 비교**하는 방식이다. 외부 AI API를 호출하지 않았으며 앱 단독 상시 생성 기능은 아직 연결하지 않았다.

앱의 **생성 비교** 또는 `http://127.0.0.1:8765/#/generation-pilot`에서 기존 브리핑/시범 생성본을 전환하고 카드·요약·방법과 결과·Methods·그림·한계를 볼 수 있다. 시범본은 기존 Library에 자동 게시하지 않으며 기존 14편과 개인 기록을 보존한다.

## 실제 수행

1. MTS 논문의 원문·표·그림 caption·SI를 44개 구간으로 묶었다. 텍스트와 연결 자산의 해시를 보관했다.
2. 생성자는 기존 한국어 카드·브리핑·비교 기준을 읽지 않고 입력 패키지, 원본 Figures 1–8, SI 5페이지를 읽어 새 초안을 작성했다.
3. 로컬 검사는 필수 필드·4개 상세 탭·주요 주장 15개의 인용문·출처 ID·그림 경로·파일 해시를 확인했다. 인용문 존재 확인을 과학적 결론의 정확성 검증으로 취급하지 않았다.
4. 별도 내용 검토자가 기존본·원문·사전에 준비한 15개 기준과 대조했다. 기존의 핵심 수치와 Methods가 유지됐고 SI·그림·대조군 설명이 보강된 것을 확인했다.
5. 검토에서 발견한 두 종류의 문제를 수정하고 다시 확인했다. 최종 상태는 **일부 검증 · 초안**이다.

## 발견과 교정

| 항목 | 최초 초안 | 최종 반영 |
| --- | --- | --- |
| 원문 caption | 4개 그림의 caption 필드에 한국어 해설이 들어감 | 원본 영문 caption 복원. 한국어 해설은 description/explanation에 유지. 입력 caption과 일치하지 않으면 거부하는 검사 추가 |
| SI 정량 설명 | DPV 보조 검증을 언급했지만 S4C의 결정계수 누락 | 실제 그림에서 확인한 R²=0.9062와 해석 범위를 추가 |

기존본 대비 SI의 대조·검량 근거, 실제 패널/본문 표기의 불일치, 공유하는 MTS 반응의 해석 한계가 더 자세하다. 일부 장비 목록은 줄였지만 결과 비교에 필요한 조건·반복·대조 논리는 유지했다. 원문 내부 상충을 임의로 통일하거나 새로운 실행용 실험 절차를 만들지 않았다.

## 남은 범위

사용자는 앱에서 비교한 뒤 **시범 생성본이 더 낫다**고 평가했다. 이후 브리핑의 구성과 설명 깊이는 이번 시범본을 기준으로 삼으며, 다음에는 다른 분야 1편에서도 같은 작성·검토 방식의 품질을 확인한다. 이 선호와 과학적 검토 상태는 별개이므로 현재 `partial` 표시는 유지한다.

- 논문 내부의 단위·반복·시간·정규화·회귀식 상충은 정답을 확정하지 않았다.
- 원시 측정값 재분석, 실험 재현, 인용문헌·외부 규제 지침의 독립 검증은 수행하지 않았다.
- 한 논문의 한 번 생성 결과다. 다른 분야와 반복 실행의 품질·처리 시간·비용·안정성을 검증한 것은 아니다.
- 기존 Library의 검토 기록을 이번 시범본의 검토 상태로 덮어쓰지 않았다. 기존본은 비교 시점의 스냅샷이다.

## 파일과 재검사

- `CONTRACT.md`: 입력·출력·검증 계약. 생성자의 지침은 프로젝트의 `BRIEFING_GUIDELINES.md`를 함께 따른다.
- `inputs/mts.json`: 기존 해설을 제외한 원문 입력.
- `baselines/mts.json`: 기존 카드·브리핑의 비교 스냅샷.
- `drafts/mts.json`: 독립 검토의 교정을 반영한 시범본.
- `runs/mts-codex-20260923.json`: 실제 생성 방식·입력과 기준 해시.
- `reviews/mts-codex-20260923.json`: 검증 결과·남은 항목. 입력/초안 해시가 바뀌면 이전 검증을 적용하지 않는다.

프로젝트 루트에서 `python generation.py`를 실행하면 현재 결과를 검사하고 `.runtime/generation-pilot/validation.json`에 기록한다. 이 명령은 새 문장을 생성하거나 모델을 호출하지 않는다. 최초 초안과 검토 전 기준, 세부 감사 로그는 `.runtime/generation-pilot/`에 따로 보존했다.

최종 자동 테스트 99개 통과. 실제 브라우저에서 기존본/시범본의 10개 보기, 원본 그림 확대, 상세 이동·뒤로가기의 선택 복원, 390px 화면을 확인했다. 기존 DB 7개 테이블 내용은 작업 전과 동일했다.

## 두 번째 분야 · Zavegepant PBPK

MTS 시범본을 선호한 사용자의 승인에 따라 ADME·PK/PD 분야 논문을 같은 방식으로 시험했다. 논문은 *Physiologically Based Pharmacokinetic Modeling to Assess Transporter-Mediated Drug-Drug Interactions in Support of Labeling Recommendations for Zavegepant Nasal Spray* (PMC13545016, DOI 10.1002/cpt.70460)이다.

- 입력: 원문 51구간(초록 1, 본문·기타 진술 25, 공식 Figure caption 4, SI 페이지 21). 연결한 원본 파일과 각 텍스트 구간의 해시를 보관했다.
- 생성: 기존 한국어 카드·브리핑·비교 기준을 보지 않은 생성자가 전체 입력, 공식 그림 4개와 SI 21쪽을 확인했다. 카드 방법·결과 3쌍, 초록 전문 번역, 상세 4탭, 원문 그림 4개, 주요 주장 15개의 근거를 작성했다. 별도 외부 AI API는 호출하지 않았다.
- 독립 검토: 생성 전 마련한 15개 기준에 초록 번역·Methods 깊이를 더해 17항목을 확인했다. 현재 검토에서는 수정이 필요한 내용 오류를 발견하지 못했다. 원문 caption·Figure 연결·인용문·수치와 분모를 대조했고 검토를 최종 입력/초안 해시에 연결했다.
- 결과: 기존 핵심 내용을 유지하면서 보정에 사용한 자료, 별도 검증 자료, 미시험 예측을 명확히 분리했다. AUC 계산 구간과 예측/관찰 비율을 구분하며, SI 민감도·검증 오차와 Figure 2 설명을 보강했다. 기여율의 가정과 원문 내부의 불일치도 표시했다.
- 한계: 원모델 재실행, 비공개 참가자 자료, 외부 인용문헌·현행 라벨의 별도 확인은 수행하지 않았다. 본문 읽기 완료가 모든 사실의 독립 검증 완료를 뜻하지 않으므로 최종 상태는 **일부 검증 · 초안**이다. 안전상 보류는 없었다.

파일은 `inputs/zavegepant.json`, `baselines/zavegepant.json`, `drafts/zavegepant.json`, `runs/zavegepant-codex-20260923.json`, `reviews/zavegepant-codex-20260923.json`이다. 최초 초안·사전 기준·출처와 초안 감사는 `.runtime/generation-pilot/zavegepant-*`에 보관했다.

두 편의 입력·기존본·초안·검토가 섞이지 않으며 다른 논문의 검토 파일을 잘못 연결하면 미검증으로 남는 회귀검사 2개를 추가했다. 최종 자동 테스트 **101개 통과**. 서버 재시작 후 실제 두 논문 전환, 새 논문의 10개 보기, 그림 4개 로드·확대, 기존 상세 연결·뒤로가기 상태 복원과 390px 화면을 확인했다. 기존 Library 14편, DB 7개 테이블과 기존 MTS 시범 자료를 유지했다. 앱 단독 상시 생성은 아직 연결하지 않았다.

사용자는 두 번째 비교 뒤에도 이 작성 방식을 채택했다. 두 시범본을 이후 구성·깊이의 기준으로 보존하며, 다음 단계로 수집 후보의 원자료 입력 준비와 생성·검토 상태 연결을 제안한다. 자동화의 실제 품질 검증과 제공자·모델·비용 결정은 별도다.

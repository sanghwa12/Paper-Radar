# 준비 자료에서 만든 카드·브리핑

`dose-linear-pk/`는 원자료 준비를 완료한 새 논문 1편을 현재 Codex 세션에서 작성하고 독립 검토한 결과다. 외부 모델 API 호출이나 앱 단독 자동 생성은 연결하지 않았다.

- `input.json`: 준비 자료의 텍스트·원본 파일·출처·해시 스냅샷. 준비 캐시와 별개인 `public/assets/briefs/<candidateId>/` 사본에 연결한다.
- `draft.json`: 카드, 초록 전문 번역, 요약·방법과 결과·Methods·그림·한계, 주요 주장 근거 및 실제 읽은 범위.
- `review.json`: 독립 내용 검토 결과와 미확인 범위. 정확한 입력·초안 해시에 연결한다.
- `publication.json`: 앱에 연결한 입력·초안·검토의 해시와 생성 방식·게시 시각. 내용 검토 뒤 이 기록을 작성해야 앱에 표시된다.

`generated.load_generated()`는 기존 생성 계약으로 필수 항목·출처·그림 원본 캡션·파일 해시를 확인한다. 게시 기록이 없거나, 해시가 바뀌거나, 검토가 미검증/보류/실패 상태라면 노출하지 않고 로그에 이유를 남긴다. 기존 논문 ID를 덮어쓰지 않는다. 형식 검사를 과학적 검증으로 취급하지 않으며, 허용된 표시 상태도 **일부 검증 · 초안**이다.

앱에서는 **수집 관리 → 해당 논문의 카드 보기 → 상세 브리핑**으로 읽는다. 새 카드는 논문 카드 목록과 Library에도 포함되고, 읽음·저장·메모는 기존 방식으로 독립 보관한다. 평가하지 않은 점수는 만들지 않는다. 준비 DB의 확보 시점 기록과 생성본의 내용 검토 기록은 분리한다.

검사:

```powershell
.venv/Scripts/python.exe -m unittest discover -s tests -p test_generated.py -v
node --test --test-isolation=none tests/test_preparation_ui.cjs
```

실제 원문과 대조한 범위, 발견·교정한 내용 및 화면 검증은 프로젝트 `VALIDATION.md`와 논문별 `review.json`에 기록한다. 원시 데이터·학습 코드 재실행, 새 화합물에 대한 외부 검증은 별도이며 수행한 것으로 표시하지 않는다.

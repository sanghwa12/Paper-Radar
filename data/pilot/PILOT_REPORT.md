# 시범 평가 결과 v2 · 2026-09-21

기존 후보에서 6개 분야별 원저 2편씩을 의도적으로 골랐다. 전체 후보의 대표 표본·상위 12편 또는 자동 선정 결과가 아니다. 본문 11편, 초록 1편을 검토했다. 본문 확인 범위·미검토 SI 등은 각 논문에 기록했다.

사용자가 내용 60·보정 인용 20·최근 증가 10·저널 10을 유지하기로 했다. 내용은 새로움·근거·재현 가능성·활용 가치 각 15점이며, 강점 수준을 0·5·10·15점으로 시험 평가한다. 약점에 따른 별도 감점은 없고 명시적 코드·데이터 비공개로 재현이 막히고 대안이 없을 때만 3점 시험 조정을 적용한다. 대체 경로가 미확인이면 차감하지 않고 판정을 보류한다.

## 판정 이유

### Dockformer: 대규모 가상 탐색을 위한 딥러닝 도킹

- **새로움·동향상 의미 · 10/15점**: 2D 그래프와 3D 특징을 결합해 자세·신뢰도를 예측하는 구성을 기존 도킹 방법과 구분하고, benchmark와 ablation으로 설계 기여를 제시한다.
- **근거의 탄탄함 · 15/15점**: 실험 구조와의 자세 오차를 정량화하고 학습 시기와 분리된 PoseBusters 및 구조적으로 분리한 DockGen에서 성능을 교차 확인한다. 생화학 효능을 검증했다는 뜻은 아니다.
- **재현 가능성 · 10/15점**: 모델 구조·loss·계산식·입력 정의와 benchmark 자원을 연결해 구현 경로를 파악할 수 있다. 세부 학습·실행 설정까지 재현 가능하다고 확인한 것은 아니다.
- **연구 활용 가치 · 15/15점**: 여러 benchmark와 120만 개 이상 화합물 탐색, pocket 크기·유연성 조건에서 적용을 시험하고 추론 시간·정확도·후처리 비용을 제공한다.
- **비공개 재현 제약**: 명시적인 코드·데이터 비공개는 확인되지 않았다. 공개 benchmark 경로가 있으며 코드·가중치·SI 실행 설정은 미확인이다. 미확보를 비공개로 간주하지 않는다.
- **검토 의견**: 독립 벤치마크 성능은 유용하지만 탐색 공간이 다른 baseline과의 순위를 그대로 일반적 우열로 해석하면 안 된다. 동일 pocket 조건·후처리 포함 시간과 SI 재현 설정을 확인할 필요가 있다.

### ML 예측 단백질 구조가 FEP 정확도에 미치는 영향

- **새로움·동향상 의미 · 10/15점**: 최소 최적화 조건에서 구조 출처의 영향을 비교해 전체 RMSD만으로 FEP 입력 적합성을 판단하기 어렵다는 구체적 적용 지식을 확장한다.
- **근거의 탄탄함 · 10/15점**: 133개 화합물의 실험 활성과 여러 구조 출처의 FEP를 공통 조건에서 비교하며 RMSE·오차와 반복 ML 분할의 신뢰구간을 제시한다.
- **재현 가능성 · 10/15점**: 단백질·ligand 준비, 용매·force field, 계산 시간·버전과 입력 구조를 구체화해 방법 구현 경로를 제시한다. SI workflow와 입력·출력의 완결성은 실행 검증하지 않았다.
- **연구 활용 가치 · 10/15점**: 세 scaffold와 여러 구조·분류 조건의 성능을 연결해 FEP 입력 구조 선택과 최소 최적화 워크플로의 도입 판단을 돕는다.
- **비공개 재현 제약**: SI에 활성·입력 구조·계산 출력과 KNIME workflow 접근 경로를 제공한다고 명시한다. 비공개로 인한 차단 근거는 없으며 파일 전체의 독립 재계산은 수행하지 않았다.
- **검토 의견**: 입력 구조 선택과 FEP 검증을 실제 수치·공개 workflow로 비교할 수 있다. 학습 자료에 이미 포함된 단일 표적·관련 scaffold 사례이므로 새로운 표적의 일반 성능으로 확장하지 않는다.

### 흡입 투여를 목표로 한 KEAP1–NRF2 억제제 GSK3227634 최적화

- **새로움·동향상 의미 · 10/15점**: KI-696에서 구조 치환·배좌 선호·흡입 지향 물성을 함께 최적화한 설계 기여를 이전 비공유결합 억제제와 구분한다.
- **근거의 탄탄함 · 15/15점**: 정량 결합·세포·폐 반응에 더해 결정 구조·용액 NMR·AEC·TPP가 결합과 선택성 해석을 서로 다른 측정 원리로 지지한다.
- **재현 가능성 · 15/15점**: 합성·정제부터 NMR·세포·PK·동물 투여 조건까지 자원 식별 정보와 연결하고 NMR 처리·qPCR·assay 피팅·PK 분석 절차를 제시한다. 실제 재실험을 완료했다는 의미는 아니다.
- **연구 활용 가치 · 15/15점**: 여러 유도체·세포 평가계와 IV·기관내 투여를 시험하고 효능·투과성·efflux·제거율·용해도·off-target을 연결해 폐 국소 전달 후보 선택을 뒷받침한다.
- **비공개 재현 제약**: PDB·CCDC 및 구조·SPR·NMR·분자 데이터 SI 경로가 있다. 전체 동물 개별 원자료의 공개 범위는 미확인이며, 명시적인 비공개로 인한 재현 차단 근거는 없다.
- **검토 의견**: SAR의 변화와 물성·투여 전략을 연결하는 근거가 풍부하다. 다만 기관내 투여 결과를 사람의 흡입 효과로 해석할 수 없고 일부 동물실험 보고 항목은 추가 확인이 필요하다.

### KRAS 거대고리 억제제의 bioisostere 치환과 경구 노출 개선

- **새로움·동향상 의미 · 10/15점**: KRAS macrocycle의 두 bioisostere 치환 전략을 구분하고 glucuronidation·노출·활성 변화와 연결한 구체적 설계 기여를 제시한다.
- **근거의 탄탄함 · 15/15점**: 결합 결정 구조와 세포·동물 측정을 연결하며 대사 개선을 hepatocyte MetID와 UDPGA 유무 S9 실험으로 교차 확인한다.
- **재현 가능성 · 10/15점**: 상세 합성·동물 절차, 화합물·세포·구조 식별 정보와 종양 반응 계산식을 연결해 주요 실험의 구현 경로를 제시한다. SI의 HTRF·대사체 절차 완결성은 미확인이다.
- **연구 활용 가치 · 15/15점**: 여러 KRAS 변이·nucleotide 상태, 두 종양 모델과 여러 종의 ADME·PK를 시험하고 노출 개선과 세포 활성 손실의 상충 관계를 정량화한다.
- **비공개 재현 제약**: 구조 기탁과 molecular data CSV·SI 경로가 있으며 명시적인 비공개는 확인되지 않았다. SI 미검토와 전체 PK 원자료 미확보만으로 감점하지 않는다.
- **검토 의견**: 구체적 bioisostere 설계와 실패·상충 관계를 원문 수치로 확인할 수 있어 lead optimization 학습에 유용하다. 완성된 우수 후보라는 의미의 우선 검토는 아니다.

### NCS-1 결합 부위 탐색과 PPI 조절 hit 검증

- **새로움·동향상 의미 · 10/15점**: 새 NCS-1 subpocket hit 계열과 조반응액을 직접 검증하는 fragment-to-hit 통합 사이클을 제시해 기존 접근의 적용 범위를 구체적으로 확장한다.
- **근거의 탄탄함 · 15/15점**: GCI와 결정학으로 결합을 확인하고 E14의 세포 PPI 효과를 co-IP·PLA로 교차 확인한다. 각 측정의 대조 조건도 제시한다.
- **재현 가능성 · 15/15점**: 검토한 SI의 결정화·계산 선택·로봇 합성·GCI·세포 분석 조건을 자원 ID 및 HIPPO 역사 버전·선택 입력·출력과 연결해 재구현 경로를 제시한다. 저장소 전체를 실행한 것은 아니다.
- **연구 활용 가치 · 15/15점**: 여러 scaffold·subpocket에서 적용을 시험하고 3개월 사이클, 시약·합성·구매 비용과 처리량·hit rate를 제시해 도입에 필요한 자원과 성능을 판단할 수 있게 한다.
- **비공개 재현 제약**: PDB 구조·Zenodo 원시/처리 데이터와 역사 버전·입력/출력을 포함한 공개 코드 경로를 명시한다. 비공개에 따른 조정 사유는 확인되지 않았으며 사용자 환경에서 실행 검증한 것은 아니다.
- **검토 의견**: 구조·생물물리·세포 결과와 코드·데이터가 연결되어 후속 연구 설계에 유용하다. 범용 성능 개선과 모든 scaffold의 PPI 조절은 입증된 것으로 취급하지 않는다.

### 새 chemotype으로 T. cruzi LysRS 표적을 교차 검증

- **새로움·동향상 의미 · 10/15점**: 다른 chromene 골격의 T. cruzi 적용과 첫 TcLysRS 결정 구조를 통해 단일 chemotype 중심의 기존 표적 검증을 확장한다.
- **근거의 탄탄함 · 15/15점**: 대조·반복을 갖춘 효소 억제에 DSF·결정 구조·세포·동물 결과를 연결해 주장을 교차 지지한다. 인용한 선행 유전학 실험을 새 검증으로 가산하지 않는다.
- **재현 가능성 · 15/15점**: 감염·노출·농도·단백질·결정화 조건과 자원 ID를 제공하고 효소 IC50 피팅·PK NCA·qPCR 표준곡선·분석 도구를 연결한다. 전체 원자료 재계산은 수행하지 않았다.
- **연구 활용 가치 · 10/15점**: 급성 감염 모델의 경구 제형·용량과 숙주 세포 독성·선택성·경구 노출을 함께 제시해 해당 표적·화합물의 후속 평가 조건을 구체화한다.
- **비공개 재현 제약**: PDB 구조와 manuscript·SI에 자료를 제공하고 추가 원자료는 요청 경로를 안내한다. 요청 시 제공을 비공개로 단정하지 않으며 전체 개별 원자료 확보·독립 재현은 미실시다.
- **검토 의견**: 효소·구조·세포·동물 수준을 연결하는 표적 검증 사례로 유용하다. 새로운 유전학 실험은 이 논문 결과가 아니며 이전 문헌의 결과를 인용한다.

## 시범 평가에서 확인한 점

- 본문 내용 점수는 40–55/60점이다. 이는 네 축의 확인된 강점에 근거한 읽기 우선순위 판단이며, 객관적·검증된 품질 순위가 아니다. 기존 20개 조건은 근거 기록으로 유지하고 항목별 3점 합산을 중단했다.
- 확정 감점은 0편이다. popPK는 원자료 비공개가 확인됐지만 공개된 식·모수에 의한 방법 재구현 가능성이 있어 감점 판정을 보류했다. 현재 내용 45점에서 차감하지 않으며 가능한 조정 범위는 42–45점이다. 원 코호트의 정확한 재분석과 대체 자료에서 방법을 재구현하는 것은 구분한다.
- OpenAlex 누적 인용은 Dockformer 3회, 나머지 11편은 0회다. 신규 논문에 현재 백분위를 즉시 점수화하면 불안정한 서열이 생길 수 있어 인용 배점은 유예했다. 처음 확보한 관측값이므로 최근 증가량은 계산하지 않았다.
- NCS-1은 동일 DOI의 OpenAlex 기록 두 개가 다른 발행일·보정 백분위를 제공한다. 인용수는 두 기록 모두 0이지만 보정 백분위는 단일 값으로 확정하지 않았다.
- JCR 공식 화면에서 10개 저널의 2025 JIF·분류·백분위를 확인했다. 여러 분류가 있는 저널은 모든 분류 백분위의 중앙값을 시험적으로 사용했고 최고값을 골라 쓰지 않았다. 저널 점수는 백분위×0.1이다. 학교의 브라우저 열람과 Journals API 권한은 별개다.
- 출판사 온라인 발행일과 Europe PMC 발행일이 다른 경우 둘 다 표시했다. 이번 표본에 일부 30일 이전 온라인 발행 논문이 포함된 것은 원래 후보 메타데이터와 원문 날짜의 차이 때문이다. 향후 운영 날짜 기준도 출처와 함께 정리해야 한다.
- MetaVision-SPR은 교내 브라우저에서 CAPTCHA가 표시돼 초록만 평가했다. 이는 구독 권한 없음이나 논문 결함의 증거가 아니다.
- 고정 통과점·선정 편수·주기·유료 AI 연결은 확정하거나 구현하지 않았다. 이 결과는 사람이 읽은 근거를 기록한 시범 자료이고, 새 후보의 자동 평가 서비스가 아니다.

## 근거와 재계산

앱 `#/evaluation`은 요약과 간략한 참고 점수만 표시한다. 네 축의 점수 근거와 기존 240개 확인 조건·본문 위치·출처는 아래 평가 자료에 보존한다. v2 판정은 `ratings-a.json`, `ratings-b.json`, 원문 근거는 `reviews-a.json`, `reviews-b.json`, 선택 메타데이터는 `selected.json`, 지표와 조회 시각은 `citation-metrics.json`, `journal-metrics.json`에 있다. `evaluation.py`가 이 저장 자료로 점수를 계산한다. API 또는 새로고침에서 자료를 읽으며 외부 지표를 자동 갱신하지 않는다.

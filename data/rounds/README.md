# 선정 회차

`20260923-01.json`은 2026-08-25~2026-09-23의 새 원저를 여섯 분야에서 한 편씩 고른 첫 회차다. `#/rounds`에서 최신 여섯 편을 보여준다. 원문을 먼저 열거나 아직 없는 카드·브리핑 링크를 만들지 않는다.

## 선정 범위

- Europe PMC 메타데이터를 분야별 최근순·관련도순 각 40편 이내로 조회했다. 13회 요청 중 9회 유효 응답, 4회 `version`만 반환한 불완전한 응답이었다. 실패를 0편으로 해석하지 않았다. ADME는 짧은 검색식의 최근순 결과로 보완했다. 검색식·결과 수·조회 수·시각은 manifest에 기록했다.
- 성공 응답 360건에는 중복이 있다. 분야 내 중복 제거 후 345건에서 기존 보관·Review·Preprint·기타·유형 미확인·초록 없음 등을 제외한 90개 분야별 후보 항목의 초록을 비교했다. 같은 논문이 여러 분야에 등장할 수 있다. 전체 문헌을 조사하거나 모두 점수로 정렬한 결과는 아니다.
- 최종 여섯 편에 기존 v2의 내용 4축과 60/20/10/10 배점을 적용했다. 분야 적합성·접근의 다양성을 함께 고려한 잠정 추천이다. 내용 점수에는 분석자의 판단이 포함된다. 유료 원문이라는 이유로 제외하거나 감점하지 않았다.
- 실제 검토는 초록·메타데이터까지다. 본문·그림·SI·원자료·코드는 미검토다. 재현성은 여섯 편 모두 미평가이며 별도 비공개 감점도 적용하지 않았다. 독립 교차 검토에서 근거가 부족한 항목은 미확인으로 수정했다.
- Europe PMC의 실제 누적 인용은 모두 0회였지만 신규 논문의 인용 배점은 유예했다. 이전 관측값이 없어 증가 배점도 미평가다. Chemical Science의 2025 JIF 8.1·백분위 80.6은 기존 공식 JCR 확인 기록을 재사용했다. 나머지 다섯 저널은 미확인이다. 총점·순위는 확정하지 않는다.

## 저장과 다음 단계

- DB에는 선정한 **6편만** 추가했다. 기존 후보 13편과 Library 15편·카드 13편·생성 비교 2편은 보존했다. 새 브리핑은 0편이다.
- 원본 메타데이터 여섯 건은 `sources/20260923-01.json`에 보관한다. 탈락 후보 풀은 `.runtime/selection-round-20260923/`의 임시 감사 자료이며 앱 DB·Git에 넣지 않는다.
- `Collector.import_selection_round()`는 선정한 여섯 원저를 한 트랜잭션으로 등록한다. 기존 식별자 충돌이나 쓰기 오류가 있으면 전체 취소한다. 네트워크 검색이나 기존 후보 병합을 시작하지 않는다.
- `GET /api/rounds`는 manifest·후보·준비 요약·실제 카드의 상태를 읽는다. 조회만으로 수집·자료 준비·작성을 시작하지 않는다. 새 PC에서 회차를 이어 보려면 현재 DB와 준비 자료 백업도 복원해야 한다.
- 자료 준비 버튼은 기존 API를 사용한다. `ready`도 작성 대기이며, 실제 검토·등록된 카드만 열람 링크로 연결한다. 2026-09-23 오류 수정 후 실제 재시도 결과는 본문 4/6·준비 완료 1(PWRules)·부분 준비 3(Collagen I·PP2A·AS-TLC)·본문 미확보 2(MGAT1·TST002, HTTP 403)다. 여섯 편 모두 과학적 내용은 미검토이며 새 브리핑은 0편이다. 현재 상태는 DB와 연결한 회차 화면을 따른다.
- 다음은 자료 확보 후 현재 Codex에서 카드·상세 브리핑을 작성·검토하는 단계다. 정기 수집 주기·앱 단독 AI 생성·외부 LLM API는 연결하지 않았다.
